Decisions resolved

The composition is an Operate surface, not a fantasy-themed marketing screen. Decoration stays behind task clarity and reliable state.

1

Familiar navigation, themed language

Each fantasy label carries a plain-language subtitle, keeping the personality assessable without making users decode the app.

2

Urgency is explicit

Due today, overdue, and important states use text plus restrained color—never color alone—so the Today queue remains predictable.

3

Create and edit share one surface

The persistent inspector avoids modal context loss. “New Quest” switches the same fields into a clean create state.

4

Stable ID is available, not dominant

The cross-app reference is copyable near the form, while the coursework title remains the primary human-readable identifier.

5

Local and Obsidian states are visible

Sync status and the save note expose the local-first sequence instead of implying that a log append controls whether an edit succeeds.
